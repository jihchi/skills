# Skills

My personal collection of [Agent Skills](https://agentskills.io).

## Getting Started

```sh
npx skills add jihchi/skills
```

## Finnish to Taiwanese Traditional Chinese

[`finnish-to-traditional-chinese-taiwan`](skills/finnish-to-traditional-chinese-taiwan/SKILL.md) translates Finnish into Traditional Chinese as used in Taiwan. It preserves the original meaning, tone, and formatting, with translation notes when needed.

## Plain text accounting with Ledger CLI

[`plaintext-accounting-ledger`](skills/plaintext-accounting-ledger/SKILL.md) helps inspect, edit, validate, and report on Ledger-compatible plain text accounting journals. It preserves local conventions and checks journal edits with Ledger CLI. It does not cover other accounting tools, bank-statement imports, or tax and accounting advice.

## Writing actionable instructions

[`writing-actionable-instructions`](skills/writing-actionable-instructions/SKILL.md) gives rules of thumb for actionable answers and documentation. It favors concrete, numbered items even when order does not matter, so readers can act without consequential guessing. Commands, inputs, safety warnings, and checks appear where relevant—not as a fixed template for every answer. It keeps simple answers short and prefers short command blocks over unnecessary scripts.
