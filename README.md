## Getting Started

```sh
npx skills add jihchi/skills
```

## Writing actionable instructions

[`writing-actionable-instructions`](skills/writing-actionable-instructions/SKILL.md) gives rules of thumb for actionable answers and documentation. It favors concrete, numbered items even when order does not matter, so readers can act without consequential guessing. Commands, inputs, safety warnings, and checks appear where relevant—not as a fixed template for every answer. It keeps simple answers short and prefers short command blocks over unnecessary scripts.
