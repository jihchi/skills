## Reading rule

Read this README during normal use. Read the full references only when a task involves an unfamiliar command, edge case, disputed accounting concept, or a workflow such as lots, prices, virtual postings, budgeting, forecasting, archiving, aliases, strictness, or formatting with `ledger print`.
